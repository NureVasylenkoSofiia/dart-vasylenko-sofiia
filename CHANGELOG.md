# Історія змін

## [1.0.0] — Лабораторна робота №4

- Перебудовано структуру проєкту з використанням каталогів `lib/src/` та `bin/`.
- Додано консольний інтерфейс з командами `list`, `add` та `holidays`.
- Реалізовано збереження й завантаження розкладу у форматі JSON.
- Додано потокове читання великих текстових файлів через `openRead()`.
- Реалізовано отримання державних свят із зовнішнього REST API через пакет `http`.
- Додано перевірку помилок HTTP-запитів та некоректних даних.
- Створено власний HTTP-сервіс на основі `shelf` і `shelf_router`.
- Реалізовано маршрути `GET /items`, `GET /items/<id>` та `POST /items`.
- Додано журналювання HTTP-запитів.
- Розширено модульні тести для CLI, JSON, файлового сховища, HTTP-клієнта та сервера.
- Додано документаційні коментарі до публічного API.

## [0.3.0] — Лабораторна робота №3

- Реалізовано асинхронне сховище занять із використанням `Future` та `async/await`.
- Додано порівняння послідовного й одночасного виконання через `Future.wait`.
- Реалізовано обробку помилок через `Future.wait` та `ParallelWaitError`.
- Додано генератор `async*`, обробку потоків через `await for` і `listen`.
- Реалізовано події розкладу через `StreamController`.
- Досліджено одноразові та широкомовні потоки, перетворення `where`, `map`, `take`.
- Реалізовано обчислення статистики в окремому ізоляті через `Isolate.run`.
- Додано модульні тести асинхронного коду.

## [0.2.0] — Лабораторна робота №2

- Створено об'єктну модель навчального заняття `Lesson`.
- Реалізовано звичайний, іменований, фабричний і первинний конструктори.
- Додано порівняння об'єктів через `==` та `hashCode`.
- Реалізовано ієрархію видів занять із використанням `sealed` і `final` класів.
- Додано `mixin`, `extension`, узагальнений репозиторій та розширений `enum`.
- Використано записи `Record` та зіставлення зі зразком.
- Перенесено обробку розкладу на об'єктну модель.

## [0.1.0] — Лабораторна робота №1

- Створено консольний застосунок для обробки розкладу занять групи.
- Реалізовано перевірку та обробку CSV-подібних записів.
- Додано фільтрацію, сортування та групування занять.
- Реалізовано обробку некоректних записів.
- Додано формування текстового звіту та базові перевірки коду.
